WHAT'S MEASURED

Multi-label topic identification

Each excerpt can contain several of four governance topics. Scoring counts a predicted topic as a true positive only when a reference label includes it. Negative and borderline excerpts expose missed synonyms and misleading mentions.

SAFE NEXT ITERATION

How to improve credibility

Collect permissioned, human-labeled public SEC excerpts; add context and negation handling; split development from held-out evaluation data; calculate per-topic precision, recall and inter-reviewer agreement. Never automate vote recommendations from matches.

PURPOSE

A concrete GTM workflow for a corporate-governance startup

This independent prototype asks: which organizations are plausible early customers, what questions should an SDR ask, and what evidence should research teams preserve? It is designed around Pennant's publicly stated target segments and its Founder's Fellow GTM responsibilities. It is not affiliated with Pennant, and the demo is not a substitute for customer interviews. This v2 also includes a 14-day experiment planner and a synthetic labeled evaluation set to expose baseline reliability limits.

01

Prioritize

Explainable weighted account scoring based on manually entered signals. Reweight factors and see the ranking change. No pretend machine learning.

02

Experiment

Write exploratory, persona-aware messages; compare A/B response rates with an honest uncertainty warning.

03

Trace

Flag board/pay/shareholder-rights themes with exact excerpt lines and a required human verification checklist.

TECHNICAL & ETHICAL LIMITS

What it does not do

  • No live SEC ingestion or API integrations.
  • No real client or investor database; examples are fictional.
  • No paid AI model call or LLM inference at runtime.
  • No outreach transmission, tracking pixels or hidden analytics.
  • No prediction of voting outcomes, conversion, or investment returns.
  • No legal advice or automated proxy-voting recommendations.
DATA HANDLING

Local by design

All calculations run in the browser. CSV imports remain in local browser storage, and exports create files on your device. Removing local browser data resets imported research. Do not place confidential employer or client information in public screenshots or GitHub uploads.
