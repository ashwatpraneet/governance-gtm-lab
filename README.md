# Governance GTM Lab

**Interactive governance-tech go-to-market portfolio | Ashwat Praneet | October 2026**

[Open the interactive website](https://ashwatpraneet.github.io/governance-gtm-lab/) · [See the Pennant Founder Fellow posting](https://www.ycombinator.com/companies/pennant/jobs/21lflHF-founder-fellow-gtm-growth-strategy)

> **Independent, AI-assisted educational prototype, not affiliated with Pennant.** All example companies, contacts, campaigns, metrics and opportunities in the app are synthetic. The software does not send outreach, connect to a CRM, use a live AI model or provide voting advice.

## What it demonstrates

| Workspace | Demo |
| --- | --- |
| GTM sprint planner | Construct a 14-day outreach experiment with adjustable assumed conversion rates and export a founder memo. |
| Account intelligence | Prioritize twelve fictional prospects with transparent, editable scoring weights. |
| Outreach studio | Draft and compare persona-specific messages; no real messages are sent. |
| Funnel experiments | Compare fictional campaign outcomes with Wilson confidence intervals. |
| Governance evidence | Highlight traceable governance themes in passages, with limitations and source references. |
| Evaluation lab | Review labeled synthetic passages, including false positives and misses, and export evaluation metrics. |

## Run the demo

Open [index.html](./index.html) in a browser. All CSS, JavaScript and sample data are contained in this one self-contained file; no server, API key, sign-in or installation is required.

The app saves data to **your own browser's localStorage**. No data is uploaded to a server.
